# Docker Multi-container setup

A multi conainer docker setup using docker compse with nginx, postgres and pgAdmin.

## Services
- **Nginx** - Web server accessible at 'http://localhost:8080'
- **PostgresSQL** - Relational database
- **pgAdmin** - Database GUI accessible at 'http://localhost:5050'

- ## Requirements
- Docker
- Docker compose

- ## Usage
- Clone the repo and run:
- ```bash
  docker compose up -d
